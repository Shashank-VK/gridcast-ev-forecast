# GridCast: EV Fleet Growth Forecaster

## Problem
Electric vehicle charging infrastructure planning requires knowing how vehicle fleets expand across geographic zones over time. Static registration counts become outdated within months because different zones experience distinct growth trajectories. Planners require zone-level forecasts evaluated against measurable benchmarks rather than static assumptions.

## Dataset
This project uses public historical vehicle registration data from the Washington State Open Data Portal:
- Dataset: [Electric Vehicle Population Size History By County](https://data.wa.gov/Transportation/Electric-Vehicle-Population-Size-History-By-County/3d5d-sdqb) (dataset identifier: `3d5d-sdqb`).
- Local vendor file: `data/ev_population_by_county_raw.csv`.
- Full provenance details: `data/PROVENANCE.md`.

The dataset records monthly counts of registered battery electric vehicles and plug-in hybrid electric passenger vehicles for Washington State counties between January 2017 and October 2026. Each county serves as a geographic zone.

## Method
1. Data Ingestion and Cleaning: Parse monthly registration records, coerce counts to integers, reindex to a continuous month-end DatetimeIndex for each zone, and forward-fill any internal gaps within the observed span.
2. Stationarity Analysis: Run the Augmented Dickey-Fuller (ADF) test using statsmodels for each zone to assess time series stationarity (p < 0.05).
3. Feature Engineering: For each zone, construct tabular features from the time series:
   - Autoregressive lags: lag 1, lag 2, lag 3, and lag 12.
   - Rolling statistics: 3-month and 12-month rolling means, shifted by one period to prevent data leakage.
   - Calendar feature: calendar month (1 through 12).
   - Deterministic trend: linear time index.
4. Model Training: Fit a scikit-learn GradientBoostingRegressor on the historical data excluding the final 12 months (after a 12-month warmup period).
5. Holdout Evaluation: Evaluate predictions on the held-out final 12 months using Mean Absolute Percentage Error (MAPE) and Root Mean Squared Error (RMSE). Compare directly against a seasonal-naive baseline that repeats the prior year's observed 12 months.
6. Recursive Multi-step Forecast: Train on all available data and recursively forecast the next 6 months for the five largest zones by current EV fleet size.

## Measured Results
The metrics below were generated by the pipeline run on real data and recorded in `outputs/metrics.json`:

- Data Range: 2017-01-31 to 2026-10-31 (118 months per zone)
- Evaluated Zones: 39 counties (all counties with at least 48 months of history)
- Overall Model MAPE: 9.65%
- Overall Baseline MAPE: 19.28%
- Overall Model RMSE: 468.65
- Overall Baseline RMSE: 1039.83

The GradientBoostingRegressor achieved a 49.9% relative reduction in MAPE compared to the seasonal-naive baseline across all 39 Washington counties.

## Installation and Execution
Create and activate a virtual environment with Python 3.12:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Run test suite:
```bash
pytest tests/ -q
```

Execute forecasting pipeline:
```bash
python -m gridcast run
```

Verification gate script:
```bash
./.builder-os/init.sh
```
